# Project agent skills

These skills are vendored for the team. Open this repository in Cursor or Codex and they are available as project skills. `.agents/skills/` is the canonical path (Cursor and Codex both read it), so the same folders are not copied under `.cursor/skills/`.

They are already in the repo. To browse or add more from the skills ecosystem, use [`npx skills`](https://github.com/vercel-labs/skills).

The first ten are the shared top-10 pack. The last four are the skills that pack calls (`grill-me`, `grill-with-docs`, `improve-codebase-architecture`, and `tdd`), taken from the same Codex install set.

| Skill | What it is for |
| --- | --- |
| `agent-browser` | Drive a browser from the agent: navigate, fill forms, click, screenshot, and check web apps. |
| `find-skills` | Discover and install other agent skills when a task might already have one. |
| `frontend-design` | Set aesthetic direction, typography, and layout so new UI does not look like a default template. |
| `grill-me` | Interview a plan or design until the weak spots are explicit. |
| `grill-with-docs` | Same interview, writing ADRs and a glossary as decisions land. |
| `improve-codebase-architecture` | Find deepening opportunities, show them in an HTML report, then grill the one you pick. |
| `microsoft-foundry` | Build, deploy, evaluate, fine-tune, and operate Microsoft Foundry agents and models. |
| `tdd` | Build features and fixes test-first (red, green, refactor), including integration tests. |
| `vercel-react-best-practices` | Apply Vercel Engineering performance rules when writing or reviewing React and Next.js. |
| `web-design-guidelines` | Review UI code against Web Interface Guidelines, including accessibility and UX. |
| `grilling` | The interview `grill-me` and `grill-with-docs` run: stress-test a plan, decision, or idea. |
| `codebase-design` | Shared deep-module vocabulary (module, interface, depth, seam, adapter) used by `tdd` and architecture review. |
| `domain-modeling` | Keep `GLOSSARY.md` and ADRs current while grilling a design. |
| `code-review` | Review a diff since a fixed point on two axes: coding standards, and match to the originating spec. |
