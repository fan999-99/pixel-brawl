# 绷住俱乐部 · 四主题 Tiled 地图包

四张地图：地底「蘑菇矿坑」、村落「歪歪村」、海底「泡泡避难所」、森林「歪树森林」。

本包包含真正可编辑的图块地图、独立像素素材、玩法对象层、Tiled 原生导出和本机路线试玩。当前为地图资产交付；原游戏的正式对战场景尚未替换为这四张新图。试玩用于检查移动、碰撞、镜头和空投，不包含战斗结算与房间联机。

## 直接打开

1. 双击「打开Tiled工程.cmd」进入地图工程。左侧 maps 文件夹中有四张 `.tmj` 地图。
2. 双击「打开地图试玩.cmd」启动本机网页。保持弹出的窗口打开，关闭窗口后本地试玩服务停止。
3. 也可直接在 Tiled 中打开 `club-maps.tiled-project`，或打开 `maps/` 中任一地图。
4. 移动、复制或分享地图时请保留整个文件夹，素材均使用相对路径引用。

本机 Tiled 路径：`C:\Users\admin\.codex\tools\tiled-1.12.2\PFiles\Tiled\tiled.exe`，版本 1.12.2。启动脚本也支持默认的 `C:\Program Files\Tiled\tiled.exe`。

每图配置 10 个模式专用出生标记：1v1 两个、2v2 四个、混战四个。1v1 使用中央 1024 像素宽的有效战区；2v2 与混战使用完整地图。1v1 的可见边界由游戏代码实现。

## 试玩按键

- A / D：左右移动；空格：跳跃，支持二段跳。
- S＋空格：从单向平台向下穿过；K：突进。
- F：拾取附近已落下的道具。此试玩只检验拾取与落点，不实现道具战斗效果。
- 「查看全图」：切换全景，白框表示当前跟随镜头范围。
- 「玩法标记」：显示碰撞、出生点、空投点和死亡区域。
- 「回到出生点」：重置本机角色。掉进深坑或走出地图边缘也会重生。

普通视图只跟随黄色角色，画面边缘提示其他角色所在方向。其余角色是位置参照，不是完整对战人机。手机显示触屏操作键。

## Tiled 图层

| 图层 | 内容与修改注意 |
|---|---|
| Background_Far | 远景图片与视差参数 |
| Scenery | 可移动、可替换的装饰组件，默认不参与碰撞 |
| Terrain_Solid | 实体地形图块 |
| Platforms_OneWay | 单向平台图块 |
| Foreground_Detail | 悬崖边缘警示等前景细节 |
| Collision | 实体碰撞矩形 |
| OneWayPlatforms | 单向平台顶部碰撞矩形 |
| SpawnPoints | 各模式出生位置；坐标表示角色脚底 |
| DropPoints | 经过安全检查的空投位置与目标表面 |
| CameraBounds | 镜头边界与跟随参数 |
| DeathZones | 掉落、越界死亡区域 |
| ModeBounds | 三种模式的有效战区 |
| AiNavigation | 平台节点、跳跃与下落候选连接 |

玩法对象层默认隐藏，便于看美术。在 Tiled 图层面板点亮眼睛即可编辑。图层名和自定义属性是本项目约定，需由游戏读取；Tiled 不会自动执行这些游戏逻辑。

**移动或增删平台时，请同步调整对应的碰撞矩形、出生点、空投点与导航节点。** 单独画一个装饰或地形图块，不会自动生成本包使用的对象碰撞。

出生点需位于安全表面，角色碰撞尺寸 32×50。跳跃设计参考现有项目参数：移动速度 265、跳跃初速度 770、重力 1720。主要路线已使用固定步长的普通跳跃与单向平台下落模拟检查，无需依赖角色专属技能。

空投从列上方落到最先碰到的安全表面，每波数量为开局参战人数（含人机）。试玩每 15 秒触发，提前 1.5 秒预告。真实联机接入时，必须由房主或服务器选择落点并同步给所有客户端。

## 文件与接入

- `maps/*.tmj`：建议继续编辑的四张源地图。
- `tilesets/*.tsj`、`tilesets/*.png`：外部图块集与可拼装装饰。
- `backgrounds/*.png`：分层背景素材。
- `exports/tmx/*.tmx`：Tiled 原生转换出的 TMX 兼容副本。
- `exports/validated/*.json`：从 TMX 再回读导出的验证副本。
- `runtime/*.arena.json`：给游戏代码使用的整理数据。
- `source/tiled_adapter.mjs`：读取对象层、选择出生点与分组抽取空投点的参考适配器。
- `preview/`：直接读取 `.tmj` 源文件与图块集的路线试玩。
- `previews/`：Tiled 原生全景 PNG、四图总览和试玩截图。

建议以 `.tmj` 为唯一继续编辑的源文件，其他导出副本在需要时重新导出。编辑源地图保存后刷新试玩页，可看到新图块和对象位置；`runtime/*.arena.json` 是交付时的快照，手工修改地图后需要重新整理。

接入原有 Phaser / Colyseus 对战时，还需要扩展 MapId 和地图选择、根据每张地图设置世界尺寸与死亡边界、把本机跟随镜头和固定 HUD 分离，以及让服务器使用同一份碰撞/出生/空投数据。旧对战仍按 1280×720 常量运行，不能只替换背景图片。

## 已完成检查

- Tiled 原生读取、TMX 导出、JSON 回读；所有图块数据和对象几何坐标一致。
- Tiled 自带 tmxrasterizer 输出四张 2048×1024 全景。
- 相对素材路径、图块引用、对象 ID、各模式安全出生点检查。
- 每图 300 次空投抽样，检查数量、去重和最上层安全落点。
- 使用现有移动参数模拟平台可达性。
- 浏览器移动、跳跃、单向下落、突进、死亡重生、四图切换和定时空投检查。

记录在 `tiled-validation.json`、`gameplay-validation.json` 和 `browser-validation.json`。

## 修改素材与重新生成

像素图块、装饰和背景为脚本绘制的原创素材，可直接在像素编辑器中继续修改；素材按 CC0-1.0 提供。Fusion Pixel 字体遵循随附的 OFL 许可。

`source/build_maps.py` 可重新生成初始地图与像素素材，需要 Python 和 Pillow。**重新生成会覆盖本包同名地图和素材，已有手工编辑请先复制备份。** Tiled 和浏览器试玩不需要运行生成脚本。

Tiled 格式与导出依据：
- https://doc.mapeditor.org/en/stable/reference/json-map-format/
- https://doc.mapeditor.org/en/stable/manual/layers/
- https://github.com/mapeditor/tiled/blob/master/docs/manual/export.rst
